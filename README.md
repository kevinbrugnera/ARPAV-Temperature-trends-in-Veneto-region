# ARPAV Temperature Trends in the Veneto Region

This repository contains the final project for the Master's course **Advanced Statistics for Physics Analysis**.

The objective of the project is to investigate whether significant long-term temperature trends can be detected at meteorological stations in the Veneto region using Bayesian statistical methods. Temperature data from three ARPAV stations are analyzed to compare a constant-temperature model against a linear-trend model, estimate station-specific parameters and uncertainties, and generate forecasts for future annual mean temperatures.

The project includes data preprocessing, exploratory analysis, Bayesian inference, model comparison, and posterior predictive forecasting.
